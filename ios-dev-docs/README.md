## 🎯 Goals
- Open and work with **Xcode projects** in Visual Studio Code
- Use **GitHub Copilot Agents** to scaffold, debug, and iterate on iOS apps
- Write clean, modern **Swift** code
- Build UIs with **UIKit** (programmatic) or **SwiftUI** (declarative)

---

## 🛠 Requirements
- macOS 13+ (Ventura or later)
- Xcode 15+
- Visual Studio Code (latest)
- GitHub Copilot subscription

---

> 💡 **Tip:** Use `@workspace` in GitHub Copilot Chat to ask questions about your entire Xcode project structure.
